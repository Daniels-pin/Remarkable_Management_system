# Remarkable API

FastAPI backend skeleton for internal operations (Barbershop module + Furniture placeholder).

## Setup

1. Create a PostgreSQL database and copy `.env.example` to `.env`.
2. From this directory, run `pip install -e ".[dev]"`.
3. Run migrations: `alembic upgrade head`.
4. Run the app: `uvicorn app.main:app --reload --host 0.0.0.0 --port 8000`.

OpenAPI docs: http://localhost:8000/docs

## Database

- Target database is **PostgreSQL** (see `DATABASE_URL` / `database_url` in settings).
- The bundled initial migration was autogenerated using SQLite for portability; it uses `String(32)` for enum-backed fields so **lowercase** values (`admin`, `open`, …) match the app’s `StrEnum` definitions.
- Run: `alembic upgrade head`.

## First admin user

There is no public signup. Create the first admin directly in the database (or add a one-off script): insert into `users` with `role='admin'`, `password_hash` from `passlib.hash.bcrypt`, and `must_change_password` as needed.

## Layout

- `app/routers` — HTTP routes (thin).
- `app/services` — business logic and transactions.
- `app/models` — SQLAlchemy ORM.
- `app/schemas` — Pydantic DTOs.
- `app/auth` — password hashing and session helpers.
- `app/middleware` — request ID, future RBAC/session context.
- `app/modules` — per–business-module namespaces (Furniture is stub only).

## API surface (v1)

- `GET /healthz`
- `POST /api/v1/auth/login` — cookie session
- `GET /api/v1/auth/session` — idle extension + expiry metadata for UI warnings
- `POST /api/v1/admin/users/{id}/impersonate` — admin only, no nesting
- Barbershop catalog + ledger list stubs; Furniture returns `501` on sample route.
